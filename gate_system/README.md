# gate_system

Локальная система 24/7: камера видит машину → система читает российский номер →
если он в белом списке, реле «нажимает» вход START/SbS блока откатных ворот
**Nice Robus**. Управление и уведомления — Telegram-бот. Без интернета всё
работает, кроме Telegram.

Разработка — на Маке (реле в тестовом режиме), работа — на **Raspberry Pi 5**.

## Установка на Raspberry Pi 5

### 0. Что нужно на чистой Pi OS

Почти ничего: всё ставит `deploy/install.sh`. Вручную нужен только **git**,
чтобы скачать проект. Для справки, скрипт сам ставит:

| Что | Зачем |
|---|---|
| git, curl, build-essential, python3-dev | загрузка кода и сборка пакетов |
| ffmpeg, libgl1, libglib2.0, libturbojpeg, libopenblas | видео и библиотеки OpenCV/Nomeroff |
| sqlite3 | база данных (и просмотр её вручную) |
| liblgpio1 + Python-пакеты gpiozero, lgpio | реле на GPIO Pi 5 |
| **uv** + **Python 3.12** | Nomeroff работает только на 3.11–3.12 |
| PyTorch (CPU), ultralytics, nomeroff-net, python-telegram-bot … | из `requirements.txt` в `.venv` |
| rpi-connect-lite | удалённый доступ |

### 1. Скачать проект

```bash
sudo apt update && sudo apt install -y git
git clone https://github.com/PavelFarniev/untitled20.git ~/untitled20
cd ~/untitled20/gate_system
```

### 2. Перенести конфиг с секретами

`config.json` (токен бота, ключ proxy6, пароли камер) в git не хранится.
На **Маке** (подставьте своего пользователя Pi):

```bash
scp ~/WebstormProjects/untitled20/gate_system/config/config.json \
    ПОЛЬЗОВАТЕЛЬ@gate.local:~/untitled20/gate_system/config/
```

Если не переносить, установщик создаст `config.json` из примера, и его надо будет
заполнить.

### 3. Установка

```bash
cd ~/untitled20/gate_system
bash deploy/install.sh        # 10–20 минут, БЕЗ sudo (пароль спросит сам)
sudo reboot                   # один раз, чтобы применились права на GPIO
```

### 4. Настройка и запуск

```bash
nano ~/untitled20/gate_system/config/config.json   # см. раздел «Что настроить в конфиге»
sudo systemctl start gate_system
journalctl -u gate_system -f                       # живой журнал (Ctrl+C — выйти)
```

После старта распознаванию нужно 1–2 минуты на загрузку моделей. В «📊 Статус»
в это время будет «Распознавание: загружается».

## Как система переживает отключение электричества

После установки ничего запускать руками не нужно:

1. Свет дали → Pi включается сам (у Pi 5 нет кнопки «вкл», он стартует при подаче
   питания) → загружается ОС.
2. **systemd** запускает `gate_system.service` (включён командой `systemctl enable`
   в `install.sh`), не дожидаясь входа пользователя.
3. Сервис запускает `…/gate_system/.venv/bin/python main.py`.
   **Активировать `.venv` не нужно:** python, взятый по полному пути изнутри
   `.venv`, сам использует библиотеки этого окружения. `source activate` нужен
   только человеку в терминале.
4. Камеры загружаются дольше Pi: система переподключается к ним сама (1 → 2 → 4 …
   30 с). Интернет появится позже — Telegram подключится сам.
5. Упал процесс → systemd поднимет его через 5 с (без лимита попыток).
   Завис поток камеры → watchdog перезапустит процесс. Зависла ОС → аппаратный
   watchdog перезагрузит Pi.
6. База SQLite в режиме WAL не портится при внезапном отключении. Файловую систему
   Pi OS проверяет при загрузке сама.

Рекомендации для 24/7:
* **батарейка часов** (официальная Raspberry Pi 5 RTC Battery): без неё после
  отключения света и без интернета часы Pi «отстают» до синхронизации, и время
  событий в истории будет неверным;
* карта *High Endurance* или SSD; при частых отключениях — небольшой ИБП.

## Удалённый доступ

* **Дома:** `ssh ПОЛЬЗОВАТЕЛЬ@gate.local` (SSH включается в Raspberry Pi Imager).
* **Откуда угодно — Raspberry Pi Connect** (ставит `install.sh`). Один раз на Pi:

  ```bash
  rpi-connect signin
  ```

  Откройте показанную ссылку и войдите (или зарегистрируйтесь) в Raspberry Pi ID.
  После этого терминал Pi доступен в браузере на **connect.raspberrypi.com** с
  телефона или ноутбука, без проброса портов и белого IP. Он работает сразу
  после загрузки Pi, вход в систему не нужен.
* **Повседневное управление** — Telegram-бот (открыть ворота, фото, статус,
  белый список, перезапуск системы).

Обновить код удалённо: на Маке `git push`, на Pi (через Connect)
`cd ~/untitled20/gate_system && bash deploy/update.sh`.

## Что настроить в конфиге (`config/config.json`)

| Секция | Ключ | Что ставить |
|---|---|---|
| `cameras` | `name`, `rtsp_url`, `role` | камеры (см. ниже); секцию `camera` можно удалить |
| `telegram` | `token` | токен от @BotFather |
| | `owner_id` | ваш числовой ID (узнать у @userinfobot) |
| | `proxy_url` | прокси вручную, если Telegram блокируется (иначе `""`) |
| `proxy` | `enabled`, `api_key` | автопокупка прокси proxy6 (см. ниже) |
| `relay` | `enabled` | `false` — тестовый режим; `true` — реальное реле (после проверки) |
| | `gpio_pin`, `active_high` | 17 и `true` для модуля с перемычкой H |
| | `pulse_ms`, `min_interval_s` | длина импульса 500 мс; защита от двойного импульса 3 с |
| `access` | `antireplay_window_s` | не открывать одному номеру чаще, чем раз в N секунд (180) |
| `detection` | `plate_conf`, `idle_interval_s`, `active_hold_s` | обычно не трогать |

Остальное — со значениями по умолчанию. Конфиг читается при старте: после правки
`sudo systemctl restart gate_system` (или «⚙️ Настройки → 🔄 Перезапустить систему»
в боте; часть настроек можно менять прямо в боте).

## Камеры

```json
"cameras": [
  {"name": "въезд", "rtsp_url": "rtsp://admin:ПАРОЛЬ@192.168.1.64:554/…", "role": "entry", "require_motion": false},
  {"name": "выезд", "rtsp_url": "rtsp://admin:ПАРОЛЬ@192.168.1.65:554/…", "role": "exit",  "require_motion": true}
]
```

* **Подключение:** камеры, Pi и роутер — в PoE-свитч (802.3af/at): камеры получают
  питание по кабелю, все в одной сети.
* **IP-адрес:** задайте камерам **статические IP** (в веб-интерфейсе камеры или
  привязкой в роутере), иначе после перезагрузки роутера адрес может смениться.
* **RTSP-адрес** зависит от производителя. Частые варианты:
  Hikvision — `rtsp://логин:пароль@IP:554/Streaming/Channels/101`;
  Dahua — `rtsp://логин:пароль@IP:554/cam/realmonitor?channel=1&subtype=0`.
  Проверить адрес можно на Маке в VLC (Файл → Открыть сеть).
* **Роли:** въезд срабатывает на любую машину с номером. Выезд
  (`require_motion: true`) — только на **едущую**: стоящая за воротами машина
  ворота не откроет и процессор не грузит. Пока кто-то заезжает, выезд на минуту
  «глушится».
* **Нагрузка:** поставьте в камере 10–15 кадров/с, 1080p (или 720p, если номер в
  кадре крупный).

## Прокси для Telegram

Нужен, только если Telegram у провайдера работает с перебоями.

* **Вручную:** `telegram.proxy_url = "socks5://логин:пароль@IP:порт"`.
* **Автоматически через proxy6.net:** `proxy.enabled = true`, `proxy.api_key` —
  ключ из личного кабинета proxy6. Система сама берёт IPv4-прокси (Нидерланды) на
  30 дней и за 3 дня до окончания покупает **новый** (новый IP, без продления).
  Ограничения: не больше 3 покупок за 30 дней и не чаще раза в сутки. История
  покупок хранится в `data/proxy_state.json`, поэтому лимиты действуют и после
  перезапуска. На балансе proxy6 должны быть деньги.
* Ключ и пароли прокси в журнал не попадают (маскируются).

## Подключение реле к Nice Robus

> Подключайте при **обесточенном** блоке ворот и выключенном Pi. Выводы Pi с
> блоком ворот напрямую не соединяются — только через контакты реле.

| Модуль реле | Raspberry Pi 5 |
|---|---|
| VCC / DC+ | ножка 2 (5V) |
| GND / DC− | ножка 6 (GND) |
| IN / S | ножка 11 (**GPIO17**) |

Контакты реле `COM` и `NO` подключите к клеммам **SbS / «Пошагово»** и **COM**
блока Nice (смотрите наклейку или инструкцию блока). На модуле с перемычкой H/L
поставьте **H** (`active_high: true`). На модуле только Low-trigger поставьте
`active_high: false`; если реле после импульса не отпускает — питайте модуль от
3.3V (ножка 1).

Проверка: `sudo systemctl stop gate_system && .venv/bin/python tools/relay_check.py --times 3`.
Три щелчка → `"relay": {"enabled": true}` → `sudo systemctl start gate_system`.

В блоке Nice включите **автозакрытие** (система только открывает) и, если есть,
режим **«Кондоминиум»**: тогда повторный импульс не остановит открывающиеся ворота.

## Решение проблем

| Симптом | Что проверить |
|---|---|
| Реле не щёлкает | `tools/relay_check.py`; ножки 2/6/11; перемычка H/L и `active_high`; был ли `sudo reboot` |
| «Реле: ⚠️ ошибка GPIO» | `journalctl -u gate_system`; пользователь в группе `gpio` |
| «Камера: ОШИБКА (нет кадров)» | `rtsp_url`, пароль; `ping IP_камеры`; адрес в VLC |
| «Распознавание: загружается» > 5 мин | `.venv/bin/python tools/download_models.py` (часто — обрыв интернета при первом скачивании) |
| Бот молчит | `telegram.token`, интернет, прокси |
| Неверное время | `timedatectl`; батарейка RTC |
| Перегрев | активный кулер Pi 5 |

Архитектура — в [`ARCHITECTURE.md`](ARCHITECTURE.md).
